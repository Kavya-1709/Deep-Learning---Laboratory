# Experiment 03 - Convolutional Neural Network for Image Classification

## Overview

This project implements a **Convolutional Neural Network (CNN)** using **PyTorch** for multi-class image classification using the **CIFAR-10 Dataset**. The experiment demonstrates the fundamental concepts of convolutional neural networks, including convolution operations, kernel size, stride, padding, feature map generation, pooling, CNN architecture construction, model training, evaluation, and visualization of the learning process.

The experiment also analyzes how different convolution kernel sizes, stride values, and padding configurations affect the spatial dimensions of feature maps.

---

## Objective

* Understand the working of **Convolutional Neural Networks (CNNs)** for image classification.
* Implement convolution operations using PyTorch.
* Study the effect of different **kernel sizes, strides, and padding** on feature map dimensions.
* Visualize feature maps generated by a convolutional layer.
* Compare **Max Pooling** and **Average Pooling**.
* Construct and train a CNN for multi-class image classification.
* Evaluate the trained model using standard classification metrics.
* Visualize training and validation performance using learning curves.
* Analyze model performance using a **confusion matrix** and classification report.

---

## Convolution Analysis

The experiment studies the effect of different convolution kernel sizes on a 32 × 32 input image using stride = 1 and padding = 0.

| Kernel Size | Output Size |
| ----------- | ----------- |
| 3 × 3       | 30 × 30     |
| 5 × 5       | 28 × 28     |
| 7 × 7       | 26 × 26     |

The convolution output dimension is calculated using:

**Output Size = ((N − F + 2P) / S) + 1**

where:

* `N` = input dimension
* `F` = kernel/filter size
* `P` = padding
* `S` = stride

---

## Stride and Padding Analysis

A 3 × 3 convolution kernel is used to study different stride and padding configurations.

| Configuration           | Output Size |
| ----------------------- | ----------- |
| Stride = 1, Padding = 0 | 30 × 30     |
| Stride = 2, Padding = 0 | 15 × 15     |
| Stride = 1, Padding = 1 | 32 × 32     |
| Stride = 2, Padding = 1 | 16 × 16     |

This demonstrates how increasing the stride reduces the spatial dimensions, while padding can be used to preserve or control the spatial dimensions.

## Pooling Comparison

The experiment compares:

* **Max Pooling**
* **Average Pooling**

Both use:

* Kernel size = 2 × 2
* Stride = 2

The original feature maps have dimensions:

**32 × 32**

After both Max Pooling and Average Pooling:

**16 × 16**

Max pooling preserves the strongest activations, while average pooling produces a smoother representation.

## CNN Architecture

The CNN consists of two convolutional blocks followed by a fully connected layer.

**Architecture:**

```text
Input (3 × 32 × 32)
        ↓
Convolution (3 → 16, 3 × 3, Padding = 1)
        ↓
ReLU
        ↓
Max Pooling (2 × 2, Stride = 2)
        ↓
Convolution (16 → 32, 3 × 3, Padding = 1)
        ↓
ReLU
        ↓
Max Pooling (2 × 2, Stride = 2)
        ↓
Flatten
        ↓
Fully Connected Layer (2048 → 10)
        ↓
Output Logits
```

The final fully connected layer produces **10 output values**, corresponding to the 10 CIFAR-10 classes.

`CrossEntropyLoss` is used during training, which internally handles the Softmax operation for multi-class classification.
