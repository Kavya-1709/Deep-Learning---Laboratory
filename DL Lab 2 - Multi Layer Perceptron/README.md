# Experiment 02 - Multi-Layer Perceptron for Image Classification

## Overview

This project implements a **Multi-Layer Perceptron (MLP)** using TensorFlow/Keras for multi-class image classification using the **Fashion-MNIST Dataset**. The experiment demonstrates the complete deep learning workflow, including data preprocessing, baseline model construction, training, evaluation, hyperparameter optimization, and visualization of the learning process.

---

## Objective

- Understand the working of a multi-layer feedforward neural network.
- Implement an MLP classifier using TensorFlow/Keras.
- Perform multi-class image classification using the Softmax activation function.
- Optimize model performance through hyperparameter tuning.
- Evaluate the model using standard performance metrics.
- Visualize the learning process through various plots.

---

## Dataset

**Dataset:** Fashion-MNIST Dataset

**Source:** Keras Datasets (`tensorflow.keras.datasets.fashion_mnist`)

**Instances:** 70,000 (60,000 training + 10,000 testing)

**Features:**
- 28x28 grayscale pixel images (784 flattened pixel values)

**Classes:**
- 0 – T-shirt/top
- 1 – Trouser
- 2 – Pullover
- 3 – Dress
- 4 – Coat
- 5 – Sandal
- 6 – Shirt
- 7 – Sneaker
- 8 – Bag
- 9 – Ankle boot
