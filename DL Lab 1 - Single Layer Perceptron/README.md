# Experiment 01 - Single Layer Perceptron for Binary Classification

## Overview

This project implements a **Single Layer Perceptron** from scratch for binary classification using the **Banknote Authentication Dataset**. The experiment demonstrates the complete perceptron learning algorithm, including weight updates, bias adjustment, model evaluation, and visualization of the learning process.

---

## Objective

- Understand the working of an artificial neuron.
- Implement the Perceptron Learning Algorithm from scratch.
- Perform binary classification using the Step Activation Function.
- Evaluate the model using standard performance metrics.
- Visualize the learning process through various plots.

---

## Dataset

**Dataset:** Banknote Authentication Dataset

**Source:** UCI Machine Learning Repository

**Instances:** 1372

**Features:**
- Variance
- Skewness
- Curtosis
- Entropy

**Classes:**
- 0 – Authentic Banknote
- 1 – Forged Banknote
